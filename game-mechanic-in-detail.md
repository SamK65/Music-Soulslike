# My Ideas for the Game Mechanic In Detail

The core mechanic of the game is the ear-training combat system. It's important to realize that designing this game is a balancing act of 3 interrelated components.

1. Pedagogy: Ear training is not the easiest or most intuitive skill to learn, so much of the game has to function as a tutorial. We need to build robust systems of visual and auditory feedback while also making sure any feedback does not give the player a way to cheat the system.
2. Engaging Combat: The ear training is the basis of combat and progression in the game. It should be fun. It should be intense, even in a tutorial (which is all we're going to be able to make). This is not an ear-training quiz pretending to be a game. It is a battle between masters.
